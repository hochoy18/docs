install-matt-pocock-skills

第一次装这一整套 skill——选 npx (editable) 或 Claude Code plugin (managed read-only)。装完之后做 setup，再上 main flow。

用途

源站在 www.aihero.dev/skills（RSS: /skills/rss.xml）列了两条安装命令——本身不是 skill，是一个一次性操作。装完才会看到 19 个 skill 加上 ask-matt orchestrator。

当前最新版本：v1.3（Oct 5, 2026），本篇写作于 2026-10-20，距 v1.3 发布两周。源站 changelog 共 6 条，本页 §history 全列。

page 1 / 2 of Precondition.
  1. install (本页) · 物理装到本机
  2. setup · per-repo 装 issue tracker / labels / domain docs
顺序：先 install（一次），再 setup（每个 repo 一次）。

npx skills@latest add mattpocock/skills

  • 写入可编辑文件，落到 ~/.claude/skills/

  • 更新：npx skills update

claude plugins install mattpocock-skills

  • 上游改 → 你自动收到（auto-update）

Method 1 · npx (editable)

源站原话："Pick the skills and agents you use. The installer writes editable files into your project."

装

npx skills@latest add mattpocock/skills

效果：把 mattpocock/skills 仓库里的 skill 拷成可编辑文件，落到本机的 ~/.claude/skills/（或同效路径）。从这一刻起你拥有本地副本——可以改 SKILL.md、可以 patch，可以 fork 出自己的版本。

更新

npx skills update

拿到上游最新版。手动节奏，不自动拉。

什么时候用

  • 想 fork / 长期改某一两个 skill
  • 想清楚检查每个更新再合入
  • 离线 / 不能上网时差量读本地已下载

Method 2 · Claude Code plugin (managed)

源站原话："Install the complete set as a managed, read-only plugin from the official marketplace."

装

claude plugins install mattpocock-skills

从 Claude Code 官方 marketplace 装 -- 整套 skill 装成 只读插件。Updates automatically.

区别要点

维度npx (editable)plugin (managed)

何时用 / 不用

用本命令

  • 第一次把 mattpocock/skills 拿到本机
  • 换了机器（rig transfer）
  • 从 plugin 换回 npx editable（或反过来）

用 npx editable

  • 计划 fork / patch 某一两个 skill
  • 想要 control update 节奏

用 Claude Code plugin

  • 纯粹使用、不改 skill 本体
  • 永远跟上 upstream 的最新词表/流程
  • 公司机器不让 npx 跑

不用 / 不在本文档范围

  • per-repo 的 issue tracker / labels / CONTEXT layout 配置 — 看 setup-matt-pocock-skills
  • 已有装、想升级 — 直接 npx skills update 或 plugin auto-update
  • 写了新 skill 想发布 — 看 /writing-great-skills（v1 引入，源站另有 doc）
