setup-matt-pocock-skills

给仓库打地基。一次性配置三件事，让其他工程 skill 能正常工作。

用途与时机

本 skill 是 ask-matt 工程流图的 Precondition： "run before your first engineering flow to configure the issue tracker, triage labels, and doc layout the other skills assume."

它解决一个前置依赖问题：/triage、/to-tickets、 /wayfinder、/grill-with-docs、/domain-modeling 等工程 skill 都需要读 docs/agents/*.md 才能跑——这个 skill 负责把它们写到位。

何时跑：新仓库的第一次、或换跟踪器（GitHub ↔ GitLab ↔ Local）时。跑过一次且没换意图，无需重跑。

三个配置文件的职责

文件决定什么默认行为
docs/agents/issue-tracker.md issue 怎么创建 / 读 / 标 / 关 看 git remote → GitHub
docs/agents/triage-labels.md 5 个状态对应的实际标签字符串 原样照搬 5 个标准名
docs/agents/domain.md 其他 skill 怎么读 CONTEXT.md / ADRs single-context + 静默缺失

写入的文件

写入 4 个文件：1 个 CLAUDE.md 段落 + 3 个 docs/agents/*.md（其中 1 个按 triage 安装情况可能跳过）。

CLAUDE.md 插入的 block

## Agent skills

### Issue tracker

[一行说在哪跟踪]. See `docs/agents/issue-tracker.md`.

### Triage labels

[一行说词汇表]. See `docs/agents/triage-labels.md`.   ← 仅在装 triage 时

### Domain docs

[一行说布局: "single-context" 或 "multi-context"]. See `docs/agents/domain.md`.
优先级规则：已有 CLAUDE.md → 改它；已有 AGENTS.md → 改它；都没有 → 问。绝不同时创建两个。

它不做什么

  • 不主动建 CONTEXT.md / docs/adr/。按 domain.md 的"proceed silently"规则，由 /grill-with-docs 边聊边建。
  • 不替你跑 gh label create。标签要在 GitHub 网页或 CLI 里手工建。
  • 不覆盖 CLAUDE.md 里 ## Agent skills 之外的段落。
  • 不替你创建 GitHub repo 或远程。
  • 不写 .scratch/（除非选了 Local 跟踪器）。

幂等性

场景行为
首次跑 + 默认答案写入 CLAUDE.md block + 3 个 docs/agents/*.md
已有产物 + 配置未变跳过写入（探测结果 = 期望结果）
已有产物 + 换了跟踪器覆盖 issue-tracker.md；用户确认其余是否改
CLAUDE.md 已有 ## Agent skills block就地修改，不追加
