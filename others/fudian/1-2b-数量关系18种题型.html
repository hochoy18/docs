例2【2024-联考】00:34#

运动会招募志愿者，第一次招募不到100人，其中男女比例为11∶7；补招若干女性志愿者后，男女比例变为4∶3。问最多能补招了多少名女性志愿者？

A.3　B.5　C.6　D.10

【答案】B

比例倍数赋值法整数倍锁定

【解法】

男女比 11∶7 赋值：男 = 11×4 = 44，女 = 7×4 = 28（此时总人数 72 < 100，符合「不到100人」）。

补招女性后男女比 4∶3，男不变仍是 44 → 44 ÷ 女 = 4∶3 → 女 = 33。

补招人数 = 33 − 28 = 5。

【板书还原】

赋值 男 44、女 28；补招后男 44 不变，44 : 女 = 4 : 3 → 女 = 33；33 − 28 = 5 → B

例3【2025-天津】03:25#

某水产养殖公司拥有若干幼体培育车间、育苗车间和藻类池。已知幼体培育车间的水体与育苗车间的水体之比为1∶4，藻类池的水体是幼体培育车间水体的50%。若每水体需配备1名管理人员，则幼体培育车间需要200㎡的管理人员比育苗车间少12人。问该公司共配备了多少名管理人员？

A.25　B.24　C.23　D.22

【答案】D

比例倍数赋值法份数法

【解法】

水体比：幼体 ∶ 育苗 ∶ 藻类 = 1 ∶ 4 ∶ 0.5，每 1 单位水体配 1 人 → 人数比 = 2 ∶ 8 ∶ 1（整体乘 2）。

设 1 份对应 k 人：幼体 2k，育苗 8k，藻类 k。

「幼体比育苗少12人」→ 8k − 2k = 12 → k = 2。

总人数 = (2 + 8 + 1) × 2 = 22 人。

【板书还原】

幼 ∶ 育 ∶ 藻 = 1 ∶ 4 ∶ 0.5 → 人数 2 ∶ 8 ∶ 1；2 份比 8 份少 12 人 → 1 份 = 2 人；合计 (2+8+1)×2 = 22 → D

例4【2024-联考】04:49#

大学生创业主要集中高科技、智力服务、连锁加盟和自媒体运营四个领域。某学院今年选择创业的大学毕业生不到50人，其中选择智力服务领域、连锁加盟领域和自媒体运营领域的分别占1/7、1/7和1/3。那么该学院今年选择高科技领域创业的大学毕业生有多少人？

A.1　B.3　C.5　D.7

【答案】A

比例倍数反比例最小公倍数

【解法】

高科技占比 = 1 − 1/7 − 1/7 − 1/3 = 1/42。

总人数必须是 42 的倍数，又「不到50人」→ 总人数 = 42。

高科技人数 = 42 × 1/42 = 1 人。

【板书还原】

1 − 1/7 − 1/7 − 1/3 = 1/42；总人数 = 42 的倍数且 < 50 → 42 人；高科技 = 42/42 = 1 → A

例5【2020-江苏】06:06#

某企业预计今年营业收入增长15%，营业支出增长10%，营业利润增加600万元。已知该企业去年的营业利润为1000万元，则其今年的预计营业支出是：

A.9000万元　B.9900万元　C.10800万元　D.11500万元

【答案】B

经济利润比例倍数方程组

【解法】

设去年收入 R、去年支出 S：R − S = 1000（去年利润）。

今年利润 = 1.15R − 1.1S = 1000 + 600 = 1600。

代入 R = S + 1000：1.15(S + 1000) − 1.1S = 1600 → 0.05S = 450 → S = 9000（去年支出）。

今年预计支出 = 1.1 × 9000 = 9900 万元。

【板书还原】

去 R − S = 1000；今 1.15R − 1.1S = 1600；代入得 0.05S = 450 → S = 9000；今支 = 1.1S = 9900 → B

例6【2025-联考】07:07#

某小区组织“情满金秋”柑橘采摘活动，参加人员按年龄分成老年组、中年组、青年组。老年组、中年组的人数之比为5∶2，中年组、青年组的人数之比为3∶4，老年组、中年组、青年组平均每人采摘速度之比为1∶2∶3。已知青年组共采摘80斤柑橘，那么三组人员一共采摘柑橘：

A.170斤　B.212斤　C.255斤　D.298斤

【答案】A

比例倍数效率=人数×速度比例赋值

【解法】

人数比：老年 ∶ 中年 = 5∶2，中年 ∶ 青年 = 3∶4 → 老年 ∶ 中年 ∶ 青年 = 15 ∶ 6 ∶ 8。

效率 = 人数 × 速度：15×1 ∶ 6×2 ∶ 8×3 = 15 ∶ 12 ∶ 24。

青年组 24 份对应 80 斤 → 1 份 = 80/24 斤；老年 15 份 = 50 斤，中年 12 份 = 40 斤。

三组合计 = 50 + 40 + 80 = 170 斤。

【板书还原】

人数 15 ∶ 6 ∶ 8，速度 1 ∶ 2 ∶ 3 → 效率 15 ∶ 12 ∶ 24；青 24 份 = 80 斤 → 老 50 斤 + 中 40 斤 → 合计 170 斤 → A

小何在网络二手交易平台按照每张150元的价格转手了两张珍藏版CD，其中一张盈利25%，另一张亏损25%，则小何转手这两张CD总的盈亏情况是：

例8【2019-新疆】16:34#

某超市购入800斤桃子，第一天售价为进价的1.8倍，销售额为1620元；第二天售价为进价的1.5倍，销售额为900元；第三天售价为进价的1.2倍，第四天以进价的八折销售，两天销售额均为360元。第四天营业结束后发现还剩50斤未卖出。问该超市购买桃子花了多少钱？

A.2240元　B.2400元　C.2800元　D.3040元

【答案】B

乘积模型设单位量总销量倒推

【解法】

总花费 = 重量 × 单价 = 800 × 进价，设进价为 x 元/斤。

四天销量 = 1620÷(1.8x) + 900÷(1.5x) + 360÷(1.2x) + 360÷(0.8x) = (900 + 600 + 300 + 450)/x = 2250/x。

总销量 = 800 − 50 = 750 斤 → 2250/x = 750 → x = 3 元/斤。

总花费 = 800 × 3 = 2400 元。

【板书还原】

花费 = 重量 × 单价 = 800 × x；销量和 = (900+600+300+450)/x = 2250/x = 750 → x = 3；总花费 = 800×3 = 2400 → B

例9【2024-广东】17:46#

档案室需要整理300份档案，要求每天整理的档案数量相同，且规定了完成的期限。如果要提前一天完成，那么每天需要多整理10份档案。则规定的期限为多少天？

A.6　B.7　C.8　D.9

【答案】A

乘积模型列方程天数递减

【解法】

设期限 t 天、每天 x 份：x × t = 300。

提前一天：每天 x + 10 份，天数 t − 1 → (x + 10)(t − 1) = 300。

展开：xt − x + 10t − 10 = xt → x = 10t − 10，代入 xt = 300 → 10t² − 10t = 300 → t² − t − 30 = 0。

t = 6（每天 50 份）；t = −5 舍去。

【板书还原】

xt = 300；(x+10)(t−1) = 300 → x = 10t − 10 → 10t² − 10t = 300 → t² − t − 30 = 0 → t = 6（每天 50 份）→ A
